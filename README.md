# Crypto Digest Bot
/start -> welcome + instructions. Tap "Digest" -> top coins bought (gainers) and sold (losers).
Uses the Telegram Bot API + CoinGecko public endpoint (no API key). No database.

## Deploy (GitHub + Railway)
1. Push this folder to GitHub.
2. Railway -> New Project -> Deploy from GitHub repo.
3. Variable: BOT_TOKEN (from @BotFather). No volume or domain needed.
